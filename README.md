# Dataset associated with the submission "Beyond Automation Rules: Characterising Real-World Smart Home Automation Practices" at CHI 2027

The full dataset is currently undergoing complete anonymization to ensure compliance with applicable data-protection requirements and the latest guidance from the European Data Protection Board (EDPB). It will remain unavailable until this process is complete.

`example_dataset.json` contains four fully anonymized, synthetic automation examples that illustrate the dataset structure without including data or identifiers from real users.
